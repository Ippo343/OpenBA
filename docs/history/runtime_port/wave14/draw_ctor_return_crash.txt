Wave 14 lane DRAW — the crash the FIRST live run produced, kept as evidence for
WAVE14_LANE_DRAW.md §6.4.

CAUSE: the port read `??0ImageBuffer@Video@@QEAA@XZ`'s return value, exactly as
retail does (MSVC returns `this` in RAX from a constructor). That name is PORTED
and `Video_ImageBuffer_Ctor` (runtime/src/video/buffers.cpp:387) is declared
`void`, so RAX held whatever its last expression left there — here, 1.

FIX: use the `operator new` result `p` instead. Same pointer by construction,
and independent of how any port spells its signature. The identical crash and
the identical resolution are already documented at
runtime/src/graphics/sunlight.cpp:230-247 from Wave 9.
