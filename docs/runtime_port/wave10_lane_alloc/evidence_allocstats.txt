WHY THIS IS THE CONTROL AND NOT DECORATION

SwapAllocate/SwapFree. The "patches RETIRED" line above says the wrappers are gone
for this run, so all 901,685 allocations and 540,750 frees were executed by
rtalloc::Allocate / rtalloc::Free -- the ported bodies. An armed port reporting
calls=0 reads green and means nothing; this run rules that out.
